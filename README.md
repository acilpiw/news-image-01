# news-image-01 — Friday 13 November 2026 in one image

One image summing up the world's news of Friday 13 November 2026: the
FAA system outage that grounded flights across the United States.

The image shows an airport terminal at dusk: a departure board where
nearly every flight reads CANCELLED and GROUNDED, empty gates, airliners
parked idle on the tarmac, stranded travelers waiting on their luggage,
and an air traffic control tower against an orange evening sky — the day
America's skies stood still.

## Entry

- `image.jpg` — the image (JPEG, 1024x683, 202,304 bytes)
- `main.py` — copies `image.jpg` to `/output/entry.png` (standard
  library only, deterministic, no network)

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output is byte-identical to `image.jpg` on every run.
